# Prime English A2 · Relocation & Business

Интерактивное учебное пространство группы: стартовая страница, ссылка на доску Miro, план недели по дням, задания с автопроверкой и отправка ответов преподавателю.

Открыты **Week 2 · Touchdown** (12–16 октября), **Week 3 · Home Hunt** (19–23 октября) и **Week 4 · Review & Shadowing** (26–30 октября). У каждой недели есть словарь с озвучкой и тренажёром.

## Как устроено

| Файл | Что внутри |
| --- | --- |
| `index.html` | каркас страницы |
| `css/styles.css` | дизайн (палитра Prime English, Playfair Display + Inter) |
| `js/config.js` | **настройки**: Miro, Zoom, куда отправлять ответы |
| `js/week2.js` … `js/week4.js` | содержание недель: словарь, дни, задания, ключи |
| `apps-script/Code.gs` | скрипт приёма ответов в Google-таблицу |
| `js/app.js` | логика: страницы, проверка, запись голоса, отправка |

Сайт статический и работает без сервера: его можно открыть через GitHub Pages.

## Как ответы попадают в Google-таблицу

Каждое задание дня приходит отдельной строкой: дата, ученица, неделя, день, задание, тип, ответ (с ✓ / ✗), результат автопроверки, комментарий. Колонки «Проверено» (галочка) и «Обратная связь» — для преподавателя.

Подключение (один раз):

1. Откройте таблицу → **Расширения → Apps Script**.
2. Вставьте код из `apps-script/Code.gs`, сохраните.
3. **Начать развертывание → Новое развертывание → Веб-приложение**. Запуск от имени: «Я». Доступ: «Все».
4. Разрешите доступ к таблице и скопируйте URL, который заканчивается на `/exec`.
5. Вставьте его в `js/config.js` → `submitUrl` и сохраните файл в репозитории.

Пока `submitUrl` пустой, кнопка «Отправить» открывает Telegram с готовым текстом ответов.

## Как добавить новую неделю

1. Скопируйте `js/week3.js` в `js/week4.js`, поменяйте `id`, тексты и задания.
2. Подключите файл в `index.html` перед `js/app.js`.
3. В `js/app.js` в массиве `JOURNEY` поставьте неделе `state: "now"`, а прошлой — `"done"`.
