# Prime English A2 · Relocation & Business

Интерактивное учебное пространство группы: стартовая страница, ссылка на доску Miro, план недели по дням, задания с автопроверкой и отправка ответов преподавателю.

Сейчас открыта **Week 3 · Home Hunt** (19–23 октября).

## Как устроено

| Файл | Что внутри |
| --- | --- |
| `index.html` | каркас страницы |
| `css/styles.css` | дизайн (палитра Prime English, Playfair Display + Inter) |
| `js/config.js` | **настройки**: Miro, Zoom, куда отправлять ответы |
| `js/week3.js` | содержание Week 3: дни, задания, ключи |
| `js/app.js` | логика: страницы, проверка, запись голоса, отправка |

Сайт статический и работает без сервера: его можно открыть через GitHub Pages.

## Дни недели

- **Пн · Word Power** — 20 слов с озвучкой, сопоставление, объявление о квартире, True/False, noticing, мини-текст.
- **Вт · Grammar Gym** — правило there is / there are, выбор is/are, конструктор вопросов, предлоги по плану улицы, Simple vs Continuous, чек-лист MyGrammarLab.
- **Ср · Voice Day** — запись голоса прямо в браузере, скачивание файла, критерии.
- **Чт · Live Lesson** — карта урока, ссылки на Miro и Zoom, подготовка.
- **Пт · Polish & Write** — мини-квиз, письмо агенту, can-do рефлексия.

## Как ответы попадают к преподавателю

Настраивается в `js/config.js`. Способы проверяются по порядку:

1. `submitUrl` — адрес формы (Formspree или Google Apps Script). Ответы уходят автоматически в JSON: `student`, `week`, `day`, `message`, `answers`.
2. `telegramUsername` — открывается чат с преподавателем, текст ответов уже скопирован.
3. `teacherEmail` — открывается письмо с ответами.
4. Ничего не задано — открывается «Поделиться в Telegram» с готовым текстом.

Прогресс и ответы хранятся в браузере ученицы (localStorage).

## Как добавить новую неделю

1. Скопируйте `js/week3.js` в `js/week4.js`, поменяйте `id`, тексты и задания.
2. Подключите файл в `index.html` перед `js/app.js`.
3. В `js/app.js` в массиве `JOURNEY` поставьте неделе `state: "now"`, а прошлой — `"done"`.
